LESSON LEARNED

踩雷：不要在程式裡寫資料夾名稱

# ✗ 寫死資料夾名稱
OUTPUT_DIR = Path.home() / "Desktop"
  / "project-python-spider-2026"

# ✓ 讓程式自己知道「我在哪裡」
BASE_DIR = Path(__file__).resolve().parent
OUTPUT_DIR = Path(os.getenv(
  "OUTPUT_DIR", BASE_DIR))

發生了什麼事

  • 實際資料夾是 scraper，程式寫成 spider，只差一個字
  • 程式沒有報錯，log 還顯示「已輸出」
  • CSV 被寫到另一個自動新建的資料夾
  • 找不到 watchlist.txt，默默改成「抓全部公司」
能讓程式自己判斷的路徑，就不要用人手寫。

DECISIONS & NOTES

注意事項

  • 使用官方 OpenAPI，保持低頻率（每天一次即可）
  • 「人員變動」須以實際公告用字驗證，必要時調整關鍵字
  • 上櫃端點請對照 TPEx OpenAPI 官方文件確認
